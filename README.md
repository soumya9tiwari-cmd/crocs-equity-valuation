# Crocs Equity Valuation

## Overview

This project presents a comprehensive equity valuation of Crocs, Inc. (NASDAQ: CROX) using a Discounted Cash Flow (DCF) valuation model supported by financial forecasting, comparable company analysis, and sensitivity analysis.

The objective was to estimate the company's intrinsic value by projecting future operating performance, valuing free cash flows, and evaluating the impact of key assumptions on enterprise value and implied share price.

---

## Project Objectives

- Forecast Crocs' financial performance
- Estimate enterprise and equity value using DCF valuation
- Calculate the weighted average cost of capital (WACC)
- Perform comparable company analysis
- Evaluate valuation sensitivity under different assumptions

---

## Model Components

### Financial Forecasting

- Revenue projections
- Cost of Goods Sold (COGS)
- Operating expense forecasts
- EBITDA and EBIT projections
- Capital expenditure projections
- Depreciation & Amortization
- Free Cash Flow (FCF) projections

### Valuation

- Discounted Cash Flow (DCF)
- Enterprise Value
- Equity Value
- Terminal Value
- Implied Share Price

### Supporting Analysis

- WACC estimation
- Comparable company analysis
- Three-statement financial model
- Working capital projections
- Sensitivity analysis
